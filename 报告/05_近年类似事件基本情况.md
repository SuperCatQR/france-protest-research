## 1. 黄背心（2018-11 → 2020）

### 1.1 起点与形态

**2018-11-17** 首日，触发是燃油税上调。**无组织、无领袖、无纲领**——这是它最重要的形态特征，也是它后来被反复引用的原因：它证明了几十万人可以在没有任何组织的情况下上街。

**首日数据**（内政部）：

| 指标 | 数 |
|---|---|
| 示威人数（当晚第四份公报） | **282,710** |
| 示威人数（次日汇总） | **287,710** |
| 聚集点 | **2,039** |
| 伤者 | 227（7 重伤）→ 次日上修 **409** |

### 1.2 手段与让步：三段式

**第一段，让步**：

- 2018-12-04 宣布 moratoire（暂停）；**12-05 改为彻底取消**燃油税上调
- 2018-12-10 马克龙电视讲话：SMIC +100 欧元、加班费免税、取消退休者 CSG 上调
- **loi n° 2018-1213（2018-12-24）**：紧急经济社会措施
- 2019-01-13 致法国人公开信，启动「全国大辩论」（1-15 至 3-15）
- 2019-04-25 宣布 **50 亿欧元**减税（所得税）

**第二段，镇压**：

- **2018-12-08**：89,000 警力（巴黎 8,000）+ 装甲车。当日 136,000 人上街；**1,723 次逮捕 / 1,220 次 garde à vue**（巴黎 1,082 次逮捕）
- 三类弹药大量使用（IGPN 年报 2018）：

| 武器 | 2018 全年 | 2017 对比 | 增幅 |
|---|---|---|---|
| **LBD** | **19,071 发** | 6,357 | **+203%** |
| **GMD** | **5,420 发** | 1,357 | **+296%** |
| **GLI-F4** | 1,428 发（2018-11-17 → 2019-02-04，内政部经 Amnesty 转引） | — | — |

> ⚠️ GLI-F4 的 1,428 是**运动期间**的数字，不是 2018 日历年数字，也不是 IGPN 年报口径。

**第三段，立法**：loi n° 2019-290（反打砸法，2019-04-10）。

### 1.3 结果与代价

| 指标 | 数 | 口径 |
|---|---|---|
| **死亡** | **11** | 总统 2019-01-28 开罗口径 |
| 示威者受伤 | 约 **2,500** | 当局口径（截至 2019-11） |
| 执法人员受伤 | 约 **1,800** | 当局口径 |
| **失明** | **24** | 独立记者 David Dufresne 逐案统计（参议院辩论记 25） |
| 断手 | **5** | 同上 |
| garde à vue | **10,852** | 司法部／内政部汇总（临时数据） |
| 定罪 | **3,163**（近 2,000 项 comparution immédiate） | 同上 |
| 实刑立即入监 | **400** | 同上 |
| **IGPN 调查** | **313**（约 2/3 移送司法） | 内政部 |
| IGGN 调查 | 23（5 项移送） | 内政部 |
| **至 2019 年底被定罪的警察** | **1**（2019-12-19，2 个月缓刑） | 司法报道 |

**这个不对称（313 项调查 vs 1 人定罪）是「有罪不罚」批评的事实基础。**

**经济代价**：

- 2018 年四季度 GDP 损失约 **0.1 个百分点**（国民议会 n° 2167）
- 保险赔付 **2.17 亿欧元**
- 市中心商户营业额 **−20% 至 −30%**

**民意轨迹**：

- 2018-11-27/28（Odoxa-Dentsu）：运动「justifié」**84%**
- 2018-12-11（OpinionWay-LCI）：马克龙讲话后希望运动停止 **54%**

**政治后果**：2019-05-26 欧洲选举 **RN 23.31% / LREM 22.41%**（内政部最终结果）。

**法制后果最重要**：行政个别禁止示威（CSI L. 211-4-1）**自 2019-04-04 被否后始终未入法**，2021 年全球安全法未恢复，2023 年 Retailleau 再提仍被否决。

### 1.4 Jérôme Rodrigues 案：追诉期几乎与运动等长

2019-01-26 在巴士底广场右眼失明；追诉历时七年，**2026-02-02** 巴黎上诉法院确认将一名警察移送刑事法庭，庭审定于 **2027 年 6 月底至 7 月初**。罪名：violences ayant entraîné une infirmité permanente（可判重罪刑）。

> 这个时间跨度本身就是对「司法效率」叙事的反证。

## 2. 反退休改革（2023-01 → 06）

### 2.1 起点与形态

**2023-01-19** 首次全国动员，触发是法定退休年龄从 62 岁延至 64 岁。形态：**八工会联合、单一战线**——这与 2026 年的「双线并行」形成对照。

**载体是 PLFRSS**（社会保障融资修正法），不是普通法案。这一点很关键：它使政府得以适用宪法第 47-1 条的加速期限，并最终使用 49.3。

### 2.2 时间线骨架

| 日期 | 事件 |
|---|---|
| 2023-01-10 | 政府公布方案（62→64），工会宣布 1-19 全国日 |
| **2023-01-19** | 首次全国动员：内政部「逾 110 万」，CGT「逾 200 万」 |
| 2023-01-23 | 法案（n°760）提交国民议会 |
| **2023-02-17** | 国民议会 20 日期限届满，未表决，文本转参议院（宪法 47-1 II） |
| **2023-03-07** | 全国行动日：内政部 128 万，CGT 350 万；警力 10,500 |
| 2023-03-10 | 政府在参议院启用宪法 44-3（vote bloqué） |
| **2023-03-11** | 参议院通过：**195 赞成 / 112 反对 / 37 弃权** |
| 2023-03-15 | 两院混合委员会（CMP）达成一致 |
| **2023-03-16** | **Borne 在国民议会援引 49.3** |
| 2023-03-17 | 两份 censure 动议提出；当日 310 人被捕 |
| **2023-03-20** | 两次 censure 表决：**LIOT 278**（差 9 票）、**RN 94**，均未通过 |
| 2023-03-21 | 内政部长称自运动以来「855 次逮捕、843 次 garde à vue」 |
| **2023-03-23** | 第九个行动日：内政部「近 110 万」，CGT 350 万；警力 12,000（巴黎 5,000）；**441 名警宪受伤、457 人被捕** |
| 2023-03-25 | **Sainte-Soline**（反蓄水池动员，**非退休改革**，仅时间重叠） |
| 2023-03-28 | 第十个行动日：13,000 警宪（巴黎 5,500），Darmanin 称「inédit」 |
| **2023-04-13** | 全国行动日：内政部 380,000（巴黎 42,000），工会 150 万 |
| **2023-04-14** | **宪法委员会 2023-849 DC**：六组 cavaliers 被否，核心维持 |
| 2023-04-15 | 法律公布：**loi n° 2023-270 du 14 avril 2023** |
| 2023-05-01 | 劳动节：内政部 782,000，CGT 230 万；108 名警宪受伤、291 人被捕 |
| 2023-06-06 | 末次全国行动日：内政部 281,000，CGT 900,000 |
| 2023-06-09/10 | 威尼斯委员会通过关于 49.3 的临时意见（CDL-AD(2023)024） |
| **2023-09-01** | 改革生效（64 岁目标为 1968 年出生世代） |

### 2.3 三处必须纠正的前提

1. **两次 censure 动议并非都由 LIOT 提出。** 第一次由 LIOT（Bertrand Pancher 等 90 人）提出，得 **278 票**，距 287 票门槛差 **9 票**；第二次由 **RN**（Marine Le Pen 等 87 人）提出，仅得 **94 票**。
2. **被 censure 的不是「CDD 转 CDI」条款**，而是 **contrat de travail senior**（面向 60 岁以上长期失业者的试验性合同）。
3. **地点是 Sainte-Soline（Deux-Sèvres），不是 Sainte-Solange**；且该次冲突是**反巨型蓄水池**示威，**不属于**退休改革动员序列。

### 2.4 宪法委员会裁决：政府赢了核心、丢了边角

**2023-849 DC（2023-04-14）**：

- **驳回全部程序指控**——包括「用 LFRSS 这个载体偷渡退休改革构成程序滥用」的论点。法院称 47-1 与 49.3 的**累积使用**「具有不寻常性质」（caractère inhabituel）但**不违宪**。
- **维持核心条款**：64 岁 + 加速延长缴费年限，理由是立法者为「保证现收现付制的财政平衡与可持续性」所采取的措施「并非不适当」。
- **否决六组「社会骑兵」**（cavaliers sociaux）：index senior、contrat senior、第 6 条社保征缴组织、第 10 条部分（主动类岗位公务员提前退休）、第 17 条部分、第 27 条（退休制度信息告知）。

> **这一点必须说清楚**：中文舆论里「法国宪法委员会否决了退休改革」是错的——它否决的是六项附带条款，核心的 64 岁生效了。

### 2.5 动员衰减的形态

| 日期 | 内政部 | CGT | 倍率 |
|---|---|---|---|
| 2023-01-19 | 逾 110 万 | 逾 200 万 | ≈1.8× |
| 2023-03-07 | 128 万 | 350 万 | ≈2.7× |
| 2023-03-23 | 近 110 万 | 350 万 | ≈3.2× |
| 2023-04-13 | 380,000 | 150 万 | ≈3.9× |
| 2023-05-01 | 782,000 | 230 万 | ≈2.9× |
| 2023-06-06 | 281,000 | 900,000 | ≈3.2× |

**形态判断**：不是线性衰减，而是「**高位平台—断崖—节日性反弹—低位收尾**」。3 月中下旬是平台；4-13 与 6-06 是断崖后的低谷；5-01 是劳动节带来的制度性反弹。

**双口径差距稳定在 1.8–3.9 倍**，说明两套计数方法（路段计数 vs 累计参与人次／工会自报）不可直接比较；跨日比较应**固定同一口径**。

### 2.6 结果

- **法律结果**：改革生效，核心未被撤销，六组 cavaliers 未在 2023 上半年重新立法。
- **后续变动（必须与 2023 年状态区分）**：2026 年 LFSS 将 64 岁与缴费年限日程**暂停至 2028 年**，1968 年世代回到 63 岁 9 个月。
- **民意**：1 月约七成反对；2023-04 底约 65% 支持 5-01 动员。**结构特征：反对改革的比例长期高于反对运动的比例。**
- **政治后果**：2024-06-09 解散国民议会。**但因果必须谨慎**——解散的直接触发是欧洲选举结果（RN 大幅领先），不是退休改革本身。可核实的是**时序与语境关联**，不可核实的是单线因果。
- **司法与权利代价**：权利捍卫者收到 **90 件申诉**；另有报告批评预防性 garde à vue 的合法性。
- **制度层面的代价更确定**：49.3 在 2023 年被用于财政法案与退休改革，引发**威尼斯委员会介入**，把「程序合宪性 vs 程序正当性」的争论固定下来。

## 3. Nahel 骚乱（2023-06-27 起）

### 3.1 起点与形态

**2023-06-27**，17 岁少年 Nahel 在南泰尔路检时被警察开枪打死。**无一组织发动**——纯城市骚乱，与游行示威不同轨。

### 3.2 手段：拒绝例外状态的最完整样本

| # | 手段 |
|---|---|
| 1 | **明确拒绝紧急状态**：6-29 Darmanin 驳回，理由是可以「动员大量手段而无需动用宪法的特殊工具」；7-02 巴黎警察局长称现行法框架「pour l'instant suffisantes」 |
| 2 | **警力峰值化**：6-29 晚 40,000 → 6-30 起 45,000 + 宪兵装甲车，维持至 7 月 14 日 |
| 3 | **无法律依据的行政管制**：6-30 内政部通令各省 21 时起停驶 bus 与 tram |
| 4 | **取消大型活动 + 烟火管制**：7-08 **décret n° 2023-576** 全国禁售禁携烟火制品 |
| 5 | **对平台施压而非制裁**：6-30 约见四家平台；7-04 在参议院核账。**政府同期反对设定 2 小时删除义务的修正案**——要的是配合，不是立法 |
| 6 | **速审机器全开**：6-30 circulaire pénale，强化 comparution immédiate、对未成年人附加夜间外出禁令 |
| 7 | **拒绝三项结构性改革**：不设独立警察调查机构（维持 IGPN/IGGN 部内体制）；不修改 2017-02-28 放宽开枪条件的法律；不追究种族主义问题 |

### 3.3 结果

| 指标 | 数字 | 口径 |
|---|---|---|
| 逮捕总数 | 约 **3,800** | 内政部 2023-07-19 |
| garde à vue | **4,282**（至 07-10） | 参议院报告 n° 521 |
| 车辆被焚 | **12,031** | 参议院 |
| 建筑受损 | **2,508**（含 105 座市政厅、243 所学校） | 参议院 |
| 波及范围 | **672 个市镇、95 个省** | 参议院 |
| 执法人员受伤 | 逾 1,000（782 名执法 + 3 名消防） | 参议院 |
| 保险损失 | **7.93 亿欧元 / 16,400 件** | 参议院更新口径 |
| 保险损失（另一口径） | 7.3 亿欧元 / 15,600 件 | France Assureurs 2023-09-06 |

**被捕者画像**（内政部 2023-07-19 向国民议会法律委员会报告）：

- 未成年**三分之一**
- 平均年龄 **17–18 岁**
- **逾半数不为任何警政或司法部门所知**
- **90% 法国籍**

> ⚠️ **2023 基线本身内部矛盾**：参议院 n° 521 报告称 **71% 法国籍**（即 29% 非法国籍），而 Darmanin 向委员会称**非法国籍仅 10%**。两者不能同时为真，原文也没解决。

### 3.4 参议院调查委员会的评语

**2024-04-09，报告 n° 521**（François-Noël Buffet 主持）：政府应对「**有效但部分不适应**」（effective mais en partie inadaptée），提出 **25 项建议**，同时批评未成年人司法工具不足。

### 3.5 但结构性改革一项也没落地

紧急状态没宣布、开枪规则没改、独立监察机构没设。政府成功把争议转移到「父母责任」「平台责任」「未成年人犯罪」三个议题上——**这是本案最重要的一次议题置换**。

**并且这个置换在两年后被司法推翻**：2025-06-19 第 2025-886 DC 号裁决否决了 Attal 法的少年速审核心条款（16 岁以上 comparution immédiate、以累犯为条件排除未成年减刑、16 岁以下羁押上限提至一年、对未成年人的留置）。

> Nahel 骚乱中「31% 被捕者是未成年人」这个数字，被用来推动立法，而立法又被判违宪。

### 3.6 Nahel 案本身

预审法官 2025 年 6 月命令以「故意杀人」移送重罪法庭；预审庭随后改以「暴力」定性；**2026-06-12** 最高法院撤销该改定性，认为涉事警员「知道存在致命风险」，案件发回，以「谋杀」起诉的通道重新打开。

## 4. Bloquons tout（2025-09 → 2026-03）

### 4.1 起点：一个在平台上扩散的日期，不是一个组织

**「Bloquons tout」不是组织，而是一个日期。**

起点可核实为两条线索的合流：

- 一条是 2025 年 7 月中旬起在 Telegram 与 X 上流传的「全国停摆」号召，最早可追溯到主权主义／阴谋论圈层的 Telegram 频道「Les Essentiels」
- 另一条是 **2025-07-15** 总理 Bayrou 公布 2026 年预算方向：约 **438–440 亿欧元**节约、「空白年」、拟取消复活节星期一与 5 月 8 日两个法定假日

**关键判断：这是一次「有日期、无组织」的动员。** 8 月间全国出现 150 余个「assemblées générales」（公民大会），累计参与者逾 1.5 万人，但没有任何机构能代表它发言；它被 LFI 等政党争相「认领」，却始终拒绝被领导。

### 4.2 传播链条三段

| 平台 | 功能 |
|---|---|
| **Telegram** | 组织与内部争论（「Les Essentiels」→「Indignons-nous」网络，后者以镜像域名矩阵分发海报、请愿表格与「行动指南」） |
| **TikTok** | 扩散（2025-07-24「9月10日，法国自我封城」视频：`pas de travail, pas d'école, pas d'achat`） |
| **X** | 争论与假账号放大 |

> ⚠️ Instagram 在该运动中**未见专门研究**，不能与前三者并列。2026 年高中运动才有较明确的 Instagram 使用证据。

### 4.3 时间线骨架

## 5. 高中师生抗议（2026-09 → 10-19，本次事件）

> 详细时间线见 [`02_事件时间线.md`](02_事件时间线.md)，人员构成见 [`01_事件人员构成.md`](01_事件人员构成.md)。此处只给基本情况与横向对照所需的数据。

### 5.1 起点

**2026-09-17**，克雷泰伊（马赛河谷省）**Lycée Antoine-de-Saint-Exupéry** 封锁，起因是**教师缺勤长期不补、设备不足**。随后扩散为全国性 lycée 封锁。

> ⚠️ **起点日期的分歧**：主流法媒（Ouest-France、Radio France、TF1、franceinfo）均为 **09-17**；actu.fr 09-24 与 20 Minuten 10-19 写 **09-21**（可能指「扩散日」）。司法部统计起点用「la semaine du 21 septembre」。另有 franceinfo 列出至少三处早期封锁（Le Rheu、Villeneuve-la-Garenne、Créteil）。

### 5.2 诉求（四类）

来自 USL 与 Union étudiante 的联合文本：

1. **缺教师、缺人手**（代课不到、岗位空缺）
2. **校舍破败**（与大区共管）
3. **课时与班级超载**、课表
4. **Parcoursup 焦虑**
5. （加项）**紧急投入 100 亿欧元**重修校舍、大规模招聘教师

> ⚠️ **中文圈流传的「883 亿欧元」是单位换算错误**：法语源中**不存在**这一数字。原始诉求是「**100 亿欧元**」（100 亿欧元 ≈ 883 亿港元）。这是一处必须纠正的误传。

### 三条跨案例的「代价结构」

1. **人员伤亡的分布是不对称的。** 示威者与执法者都有伤亡，但只有执法者一侧有系统统计（内政部/IGPN 按情境分类），示威者一侧只有个案与民间统计。

## 9. 一句话收束

五个案例的共同点不是「暴力」，而是**「每一次都以街头被清空结束，但没有一次解决了财政轨迹」**：

- 黄背心：政府让步 50 亿减税，但债务率仍从 111.4% 升到 112.6%（2018→2024）
- 反退休改革：改革通过了，但 2026 年被暂停至 2028
- Nahel：没有结构性警察改革
- Bloquons tout：预算另经 49.3 通过
- 高中抗议：预算 65.53 Md€、净削 1,588 岗位，尚未变动
