## 判断标准（下次归档时沿用）

一个文件该进归档，当且仅当满足其一：

1. **与另一文件逐字节相同**（用哈希验证，不靠文件名判断）；
2. **可由现存材料确定性重现**（grep 输出、格式转换、下载日志）；
3. **是一次性操作留下的脚本，且该操作的目标文件已在库**。

**不该进归档的**：任何含独有事实、独有引文、独有判定的文件——哪怕它看起来过时。过时的文件是研究轨迹的一部分，删掉就无法解释「为什么当时得出那个结论」。
