**跨报告的方法学共识**（四份共用，不再重复）：

1. **数字必须带口径与时点**。同一事件在同一天出现 1 200 / 1 800 / 2 397 三个逮捕数，是同一统计的连续上修，不是互相否定。

## 二、仓库结构

```
调查研究/
├── README.md            ← 本文件
├── 报告/                 ← 四份主题报告（成品层）
├── 核查报告/             ← 逐条事实核查记录（验证层）
├── 法律研究/             ← 法国公法规范与判例（规范层）
└── 资料来源/             ← 七个检索档案（原始层）
```

四层的关系：**资料来源**是检索到的原始材料，**核查报告**记录每条断言如何被验证，**报告**是结论，**法律研究**是规范细节的支撑。

### 各层怎么用

| 层 | 什么时候看 | 特点 |
|---|---|---|
| **报告/** | 要结论、要引用、要给别人看 | 每份带来源对照表、证据强度与未核实项 |
| **核查报告/** | 要查某条断言凭什么成立 | 逐条标注 ✓／⚠／✗／?，每条给出行号级依据 |
| **法律研究/** | 要条文号、判决号、判决要旨 | 41 项条文逐字已核，含 16 个易错点 |
| **资料来源/** | 要追某个案例的完整来源链 | 每案例含时间线／处置手段／各方反应／未核实项 |

## 七、三条使用禁令

1. **不要把「高中封锁期 90% 本省被捕」用到 10-17 身上**。那是 85% 未成年的人群，10-17 是 68–73% 成年，人群结构整个换过。这是本仓库见到最多的一处误用。
2. **不要说「法国示威中 N 人受伤」**。IGPN 按**情境**分类（maintien de l'ordre / interpellation / contrôle），不按**身份**分类（示威者／警员／第三方）。按身份分的官方数字**不存在**——这是制度事实，不是检索失败。
3. **不要把「极左」当作组织名**。`ultragauche` 是警方的行政分类（国民议会调查委员会听证原话），`black bloc` 是战术不是团体。一个没有会员名册的分类在构造上无法「宣布负责」。
